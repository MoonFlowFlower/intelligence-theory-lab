## 8. Strongest Baseline Explanation

The strongest baseline explanation is that a non-candidate mechanism with legal
passive observations, legal interventions, lookup/cache capability, graph-cache
state, direct objective optimization, or candidate-equivalent access can match
or saturate the candidate without representing a hidden self-boundary mechanism.

## 9. Strongest Invalidating Reason

The task is invalid if candidate advantage is caused by:

- access asymmetry;
- passive value, schema, order, or candidate-only-field leakage;
- graph-cache or lookup-style saturation;
- post-hoc threshold or margin choice;
- noise-floor overlap;
- candidate-authored or candidate-derived truth;
- source-pin aliasing or co-forged provenance anchors;
- replay that compares stored hashes rather than recomputing behavior;
- a second logic path used only by tests or reports.

## 10. Falsifier

The future framing is falsified if any strongest fair baseline equals, exceeds,
or comes within frozen noise-adjusted margin of the candidate; if any required
access parity, seed-isolation, provenance, replay, ablation, leakage, or
failability control fails; or if candidate advantage is within the measured
multi-seed noise floor.

## 17. Margin And Saturation Demonstrated Failing Controls

Future implementation must include callable demonstrated failing negative
controls. These controls must be real executions, not labels, fixture names,
static dictionaries, report fields, or self-reports.

Required margin failing control:

- synthetic candidate fails frozen margin;
- same callable margin gate is run;
- gate returns `close_or_downgrade`;
- result is written to `margin_failing_negative_control.json`.

Required saturation failing control:

- strongest fair interventional baseline saturates candidate within frozen
  margin;
- saturation case includes all graph-cache challengers;
- same callable saturation gate is run;
- gate returns `close_or_downgrade`;
- result is written to `saturation_failing_negative_control.json`.

Every material gate without demonstrated failability is void.

- missing-observation control;
- replay that fails closed if truth labels, evaluator-only fields,
  candidate-invisible aliases, future observations, or stored verdict values are

Required artifact:
