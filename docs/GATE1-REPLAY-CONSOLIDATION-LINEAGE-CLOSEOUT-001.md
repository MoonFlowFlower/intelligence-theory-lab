## 3. Basis for each frozen conclusion

**candidate_A_status = closed_current_operationalization.** Under frozen
zero-advantage conjunctive margins, candidate A was matched by all 23 controls;
Laplace count-table dominated everywhere including heldout pairs; the transfer
event was behaviorally a generic replay pass (≈0 vs uniform replay /
equal-compute). Closure applies to this operationalization (episodic-buffer →
compositional slow model distillation), not to all conceivable transfer
mechanisms.

**candidate_B_residue_status = closed_shuffled_same_loss_and_function_approximation_collapse.**
The residue failed on three independent axes in RESIDUE-001A: (i) order
geometry — shuffled/reverse same-loss replay matched it everywhere (the parent
killer replicated in a new, larger, non-lumpable POMDP); (ii) non-replication —
single-step replay and equal-compute training beat k=4 multi-step consistency
in the new environment, so the parent's +0.004 advantage was
environment-specific; (iii) function approximation — a 1125-parameter order-2
window model dominated the entire belief-model class by up to −0.27 nats, and
even a memoryless count table beat it on h=1 slices.

**same_agent_bridge_status = blocked_no_clean_local_mechanism.** The bridge
step was conditional on a surviving local mechanism (RESIDUE-001A rollback
plan: bridge drafting allowed only on residue pass). No candidate mechanism
survived its control battery. There is nothing to bridge.

**next_allowed_direction = model_class_reset_or_representational_gap_preflight.**
The consistent cross-environment finding is architectural: cheap parametric
sequence predictors (count tables, window models) dominate the tested
belief-model class, and no replay variant produced effects beyond generic
training. Two directions remain admissible, each requiring a NEW bounded task
card with Stage-0 freeze, external anchor, and human sign-off:

```text
(a) model_class_reset: a different model-class hypothesis (not the tabular
    belief-logits class), tested under the same control battery; or
(b) representational_gap_preflight: a design-only task that must FIRST prove,
    in closed form or by construction, that the target setting contains
    structure a bounded-order window model cannot represent, BEFORE any
    mechanism experiment is authorized in it.
```
