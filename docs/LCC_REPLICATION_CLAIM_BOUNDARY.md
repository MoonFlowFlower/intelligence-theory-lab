# LCC Replication Claim Boundary

This document defines what a future independent reimplementation may and may not claim.

## If The Contract Package Is Ready

Allowed claim:

`independent_reimplementation_contract_ready`

Meaning:

The public theory card, public I/O schema, public redteam gates, claim boundary, authorization note, and manifest are sufficient for a future human-reviewed clean-room implementation task.

Not allowed:

- Independent reimplementation has been run.
- LCC theory is supported.
- General LCC agent is authorized.
- Cycle 011 is authorized.
- EGO migration is authorized.

## If A Future Independent Run Passes

Maximum allowed future claim:

`independent_reimplementation_bounded_pass`

Meaning:

An independently authored implementation reproduced the core LCC evidence pattern under the public contract.

Still not allowed:

- LCC is proven.
- LCC is a bottom intelligence principle.
- LCC is distinct from all existing theories.
- AGI, consciousness, subjective experience, self-awareness, life, robust universal support, or EGO readiness.

## If A Future Independent Run Fails

Required downgrade:

Current Cycle 000-010 results become bounded single-lineage evidence unless a later human review authorizes a revised public contract.

Do not patch the current implementation to recover the claim.

## Baseline Boundary

Passing this independent contract would not close the strong-baseline gap. It would only justify moving to a cross-theory tournament against stronger independent implementations of:

- Model-based RL / learned dynamics planning.
- Causal graph learner plus planner.
- Active inference / expected free energy control.
- Empowerment or information-gain planning.
- Meta-RL or recurrent policy baselines.
