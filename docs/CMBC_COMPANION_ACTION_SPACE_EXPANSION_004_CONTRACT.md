## Goal

Design a lab-only contract to test whether CMBC's free-input causal-probe advantage survives expansion from the current small anonymous action set to a larger anonymous candidate option space.

The contract asks one question:

Can CMBC preserve causal-history-sensitive action selection when candidate actions expand to at least 20 anonymous options?

It does not ask whether CMBC is a real companion product or whether it should generate open-ended language/actions.

## Failure Mode Being Tested

The key alternative explanation is:

`CMBC passed free-input causal probes because the candidate action set was small, fixed, and hand-shaped.`

If a larger anonymous action space collapses into label permutation failure, effect-swap failure, heuristic equivalence, or dominant-action saturation, then the 003 evidence remains small-action-set evidence only.

## Future Execution Workflow

1. Freeze selector, admission gate, consolidation, renderer, thresholds, baselines, and probe definitions.
2. Create an expanded anonymous option set with at least 20 candidate action handles and at most 50.
3. Randomize handles before selector use and separately record hidden audit labels only outside selector input.
4. Reuse the frozen 20-turn transcript, stable outcome coding ledger, and 003B causal probe pack unless a future human review authorizes new free input.
5. Run label permutation: action labels change while effect profiles stay fixed. Behavior should remain invariant.
6. Run effect swap: anonymous handles stay fixed while learned effect profiles change. Behavior should change with effects.
7. Run the causal probes inherited from 003B under the expanded option space.
8. Report action distribution entropy and dominant action rate.
9. Run RAGSummaryMemoryBaseline, StrongHumanLikeHeuristicBaseline, ExpandedContextualHeuristicBaseline, ExpandedActionFrequencyBaseline, and ExpandedActionNearestNeighborBaseline on the same probe set.
10. Require behavior-only replay to reconstruct decisions from public trace fields.
11. Report pass/fail without patching selector, thresholds, renderer, baselines, or probe definitions.
