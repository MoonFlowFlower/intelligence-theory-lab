## Bounded Deep Audit

### Layer classification

This task is at the mechanism hypothesis layer, but `001A` itself is drafting
only. A future `001B` may test a bounded social-latent inference proxy inside a
synthetic scripted partner process. It must not test real-world participants,
personal profiles, relationship behavior, or product companion behavior.

### Problem definition audit

The correct problem is:

```text
Can a canonical micro-agent extend its Gate0/Gate1/Gate2/Gate3 shared-state
loop with social_latent_state, update it through social_prediction_error, and
use that update to change later interaction_policy, while required baselines,
ablations, leakage checks, replay checks, and mutation checks fail to explain
the result?
```

The wrong problem is:

```text
build a social agent
create a relationship-learning product
infer a real person's preferences
make a companion-like behavior demo
claim social-latent mechanism validity
enter same-agent bridge
connect to EGO
```

The strongest baseline explanation is that apparent social_latent_state effects
are solved by simpler access routes:

```text

```

If any fair baseline matches or beats the future candidate under frozen access
and frozen metrics, the correct verdict is baseline collapse, not a partial
pass.

### Strongest reason this task may be invalid

The task may be invalid if the future executable merely adds a hidden
partner-profile table, preference table, transcript index, relationship cache,
persona script, or second social policy path under the name
`social_latent_state`. It may also be invalid if verifier-only partner labels,
hidden social-state labels, fixture names, split IDs, filenames, artifact paths,
future partner responses, later-action labels, or post-hoc metrics leak into
candidate prediction, state update, interaction policy, or later action
selection.

### Falsification condition

The current framing is falsified if any required baseline or ablation explains
the future result, if social_prediction_error does not causally update
social_latent_state, if updated social_latent_state does not affect later
interaction_policy, if the loop uses a second hidden social policy path, if
trace/replay cannot reconstruct the causal chain, or if old artifacts mutate.
