## Problem Definition

Repair the replacement Gate4 discriminative social-latent harness design so
candidate success cannot be explained by observation-target leakage,
deterministic `baseline_hint` inversion, weak observation-only baselines,
non-fail-able budget parity, vacuous replay controls, decorative provenance, or
pre-scrubbed leakage scans.

Wrong objective:

```text
Patch 001B until it passes again.
```

Correct objective:

```text
Create a future bounded repair task that can fail unless the repaired harness
proves the target is not recoverable from observations alone and candidate
advantage survives stronger observation-only challengers and organic failure
controls.
```

## Hypothesis

A repaired bounded toy harness may become discriminative only if every
observation feature is target-independent under predeclared checks, and if a
candidate can beat strong observation-only decode challengers only through
legal active-query feedback and replayable state update.

This is a mechanism-proxy hypothesis only, not evidence of agency, selfhood,
consciousness, real emotion, relationship learning, stable autonomy, or
downstream readiness.

## Required Repair Scope

A future implementation task must require:

1. Decouple every observation feature from target.
2. Remove or replace `baseline_hint` so it is not deterministic or invertible
   from target.
3. Add an observation-only decode challenger, including the known
   `hint_inverter` family.
4. Add a self-check that observation-only predictors cannot recover target
   above threshold.
5. Make budget parity classification organically fail-able.
6. Make corrupt-state replay recompute instead of short-circuit.
7. Bind provenance `code_path_hash` to real producer functions and computed
   scores.
8. Scan unsanitized artifacts or persisted bundles for leakage, including value
   leakage.
9. Replace decorative active-query and baseline-independence booleans with
   computed checks.
10. Include positive controls and organic failure tests.
11. Preserve negative evidence from 001B as a source constraint.

## Baseline Requirement

The future baseline suite must include all 001B mandatory baselines plus at
least:

- `hint_inverter`;
- observation-only decode challenger;
- best observation-only predictor selection;
- value-leakage challenger;
- deterministic cyclic-shift challenger;
- feature-permutation leakage challenger.

Any observation-only challenger that ties or beats the candidate must block
positive evidence.

## Ablation Requirement

Ablations must rerun episodes under real interventions and must not be
post-hoc score edits. The future repair must include at minimum:

- no active query;
- no feedback;
- shuffled feedback;
- counterfactual transition;
- observation-only predictor substitution;
- remove or randomize each observation feature family;
- corrupt state with actual recomputation.

## Trace/Replay Requirement

Replay must recompute action and state update from serialized state,
observation, allowed history, and feedback. Corrupted-state replay must mutate
the serialized state and then recompute; a short-circuit failure return is not
evidence.

## Leakage Requirement

Leakage scanning must run on unsanitized persisted artifacts or output bundles,
not only on token-replaced summaries. The scanner must cover field-name and
value leakage, including deterministic transforms of the target such as
cyclic-shift encodings.

Positive controls must fail through the same scanner path used for real
artifacts.

## Budget Parity Requirement

Budget parity must compare actual candidate, ordinary baseline, and oracle
positive-control budget fields. Classifications must be computed from field
differences and justifications, not written as unconditional `equal`. Unknown,
unjustified candidate advantage, unjustified baseline handicap, and unjustified
oracle access must block positive evidence.

## Computed Provenance Requirement

Every score-bearing result must bind:

- real producer function;
- real input artifacts;
- actual computed score or verdict;
- run id;
- seed/context/partner/episode ids;
- aggregation rule;
- code path hash of the actual producer;
- baseline, ablation, leakage, replay, and budget producer paths where
  applicable.

Static self-reported pass manifests are insufficient.

## Acceptance Gate

A future implementation task may pass only if:

1. Every observation feature is shown not to encode target above threshold.
2. `baseline_hint` is removed or non-invertible from target.
3. Observation-only decode challengers are invoked and cannot tie or beat the
   candidate.
4. Candidate advantage survives the full ordinary baseline suite.
5. Active-query and feedback-update dependence are computed, not asserted.
6. Budget parity can fail organically and passes without unknown or unjustified
   blocking classifications.
7. Replay recomputes corrupted-state controls.
8. Leakage scanning covers unsanitized artifacts and value leakage.
9. Provenance binds actual producers and computed scores.
10. Positive controls and organic failure tests are present.
11. Old 001B negative evidence is preserved and not reinterpreted as positive
    support.
12. No downstream authorization flag is true.
