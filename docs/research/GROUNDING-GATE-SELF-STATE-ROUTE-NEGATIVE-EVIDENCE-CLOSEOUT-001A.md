## Accepted negative result (GG-COBIND-ID-001A)

Minimal linear-Gaussian world; fair baseline = **independent per-channel ridge** (competent,
λ-selected); candidate-analog = **shared rank-1 score model**; metric = held-out signal R²; 10
seeds; band `DELTA_R2 = 0.05`; consistency `≥ 8/10`. Verdict computed by boolean logic over the
trace and **replay-matched**.

- Harness verdict: `co_binding_non_identifiable__only_transfer_headroom`
- Balanced+ample — independent reproduces: **10/10 seeds** (poor-channel deltas −0.042 / −0.045,
  within band) → independent heads reproduce "co-binding" with no shared latent.
- Qualitative "intervene → all three channels change": reproduced by the independent model
  (non-discriminating).
- Positive control (sensitivity): **9/10 seeds** shared beats independent under extreme imbalance.
- Negative control (specificity): **0/10 seeds**; with no shared latent the shared model collapses
  to **negative R²** (deltas −0.96 / −1.16) while independent stays ≈0.91 → no false transfer.
- Imbalanced regime: shared beats independent on data-poor channels (deltas +0.49 / +0.27) →
  the sole residue = **multi-task transfer** under data imbalance.
- Tests: 6/6 pytest. Secret scan: clean. Stop conditions: none triggered.

The controls **diverged** (positive 9/10 vs negative 0/10), so the harness is fail-able in both
directions and not rigged to a single answer.

## Route decision

**Close the self-state co-binding framing.** The evidence the gate would rest on (coherent
interventional co-change) is non-discriminating, and on balanced data the shared-latent model
holds no advantage over independent heads. This matches the standing lineage prior (every
principled mechanism in this family collapses to a fair/observational baseline once the panel and
metric are honest).

A **reframed transfer test** (shared bottleneck vs independent heads + a shared-low-rank fair
baseline under channel-imbalanced data) is the only technically live continuation, and it is
**not** opened here: its best-case claim is "a shared bottleneck transferred in one world"
(representation sharing), which cannot speak to the original self/wanting/subjectivity goal.
