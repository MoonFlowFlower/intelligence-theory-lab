# FACG-S1-NR-DRAFT-001 - Non-Realizability version of the S-1 / fork-A criterion (one-page design note)

Status: DESIGN/ANALYSIS draft, analysis-only, NO run, NO callable, NO STEP-B. NOT a banked gate; NOT yet a working criterion (it is only a criterion once it survives Section 5). Layer: mechanism-hypothesis / identifiability instrument.
Claim ceiling: at most a sharper statement of the fork-A near-contradiction. Authorizes no subject / consciousness / electronic-life claim and does not prove fork A possible or impossible.

## 1. Motivation
Genewein et al. (ICML 2023, "Memory-Based Meta-Learning on Non-Stationary Distributions") show memory-based meta-learners amortize the Bayes-optimal predictor even on non-stationary (piecewise-stationary, hidden-switch) sources, CONDITIONAL on (i) realizability (the amortized Bayes-optimal is representable) and (ii) convergence (training reaches it). Corollary: the only possible escape from the equal-access amortization wall (CSSP/CDAP) is a FAILURE of realizability and/or convergence. The tuple mistake (FACG-TUPLE-001A) was to think non-stationarity/embodiment alone escapes; it does not. This note asks whether "non-realizable Bayes-optimal" can be turned into a FALSIFIABLE S-1 subject-separator.

## 2. Formal object
S: world state, including agent-controllable interface variables AND the (possibly endogenous) parameters of the access-generating law. O: observations. A: actions, including actions that reshape the future access distribution. M: candidate = latent state + online update U. J|V: viability/objective. Boundary: agent-controlled vs non-agent-controlled variables (possibly time-varying/endogenous).
G: a generated-access process (M's actions co-determine the future access distribution).
R: equal resource/access contract (compute C, memory, samples N, hypothesis class H) shared by M and every baseline; each baseline generates its own access path (counterfactual participation).

Candidate criterion **C_NR**: M "separates" on G iff, for every bounded-resource learner b in R at equal access, the expected shortfall of b relative to M does not vanish as resources scale within the bounded budget, AND that shortfall is attributable neither to M holding a fixed reference/oracle nor to a mere tractability gap.

## 3. The two-horn collapse (why C_NR is not yet a subject-separator)
C_NR presupposes a way to score "shortfall vs M." Case-split on whether a fixed ideal Bayes-optimal-given-access object s*_G exists:
- **Horn A - s*_G exists but is intractable.** Then by K-A1a s*_G is a fixed reference: it CAPS the claim at capability, and the non-realizability gap is exactly a bounded-compute/sample gap = **S-2 (bounded rationality / sample efficiency) -> CAPABILITY_NOT_SUBJECT -> fork B.** "Hard to amortize" is a complexity statement, not subjecthood.
- **Horn B - no fixed s*_G exists** (access is co-constructed with no fixed prior). Then there is no dominating reference to measure a shortfall against; any comparison requires fixing an objective, which re-imposes a fixed reference (-> Horn A) or leaves C undefined = **UNMEASURABLE_NOT_FALSIFIABLE / SPECIFICATION_GAP.**
Both horns are pre-existing FACG terminals. So C_NR, naively, is NOT a subject-separator: it bifurcates into capability or unmeasurable.

## 4. Strongest patch and its collapse (diagonal / self-referential non-amortizability)
Patch: make G self-referential - M's own outputs are a component of the law generating M's future access, structured so that any EXTERNAL predictor s must predict M's outputs, which depend on s's own predictions when s is embedded (a Loebian / no-fixed-point diagonalization). Then (good) K-A1a may not fire (no fixed external ideal) and the non-amortizability is structural, not a compute gap.
Collapse: fairness (counterfactual participation, equal access) requires every baseline B_i to generate its OWN access path, i.e. to be EMBEDDED in its own copy of the loop. An embedded baseline occupies the SAME self-referential position -> matches M -> FORK_A_SHADOW_DOMINATED or MECHANISM_FAMILY_REPLICATION. Self-reference is a property of BEING EMBEDDED, grantable to any equal-access baseline; it is not M-specific. The only way to make it M-specific is to tie it to M's particular identity, which is either trivial (every system equals itself) or smuggles the subjecthood it set out to prove (circular).

## 5. Survival condition (kept explicit so the route stays falsifiable)
C_NR survives -> POTENTIAL_SURVIVOR only if someone exhibits an access asymmetry that is simultaneously: (i) NOT closable by scaling bounded compute (defeats Horn A / capability), (ii) NOT grantable to an equal-access EMBEDDED baseline (defeats the Section-4 embedding move), and (iii) still supports a well-defined measurable comparison (defeats Horn B / unmeasurable). Status: **UNKNOWN / none constructed.** The only theoretical hint - that "equal access" becomes ill-defined when the agent's boundary is itself endogenous and self-defined (the enactive move) - collapses into horn (iii) the moment you try to measure it without a fixed frame.

## 6. Minimal falsifier / cheapest validation (no build)
The discriminating question: **is "equal access" symmetric under (a) compute-scaling and (b) embedding?** If yes - as it appears definitionally - the subject-specific residue provably evaporates into Horn A or the embedding move. Cheapest test = a bounded paper design sweep: attempt to name ONE G that is measurable AND has provably no amortizable dominating reference AND whose M-edge is diagnosably neither tractability nor embeddedness. If no such G is nameable within a bounded budget -> route CLOSED_BY_BOUNDED_ANALYSIS (same disposition as ACBU/CSSP). Producing even one nameable G -> POTENTIAL_SURVIVOR -> mandatory hostile re-audit (s*-optimality, access symmetry, oracle/leakage, embedding-grantability).

## 7. Verdict (does it become a falsifiable S-1 definition?)
**No - not as a working subject-separator; yes - as a sharpened, falsifiable-in-principle disjunction with three named exits.** C_NR can be stated precisely, but under our own killers it collapses along two horns (tractability->capability; no-reference->unmeasurable), and its strongest self-referential patch collapses via the equal-embedding symmetry. The net gain is real but bounded: it converts "fork A is open/mysterious" into a specific structural obstruction - *equal access is symmetric under both compute-scaling and embedding, so any constructible non-amortizability is either a capability gap or a mechanism-family property* - and it names exactly the one symmetry a survivor would have to break (currently unknown/unconstructed, and it looks near-contradictory to break without smuggling subjecthood or losing measurability).
Recommended route disposition: **DOWNGRADE fork-A-as-subject-separation toward CLOSED_BY_BOUNDED_ANALYSIS pending a Section-5 symmetry-breaker;** keep fork B running. This note is the cheapest bounded analysis; it does NOT prove fork A impossible, only that the non-realizability reframe does not escape the vise.
