# SURFACE-ADMISSION-CONTRACT-ENFORCEMENT-001A

Task layer: engineering-governance / contract enforcement / no mechanism surface.

This task creates only a local authorization checker for future surface-admission task-card manifests. No Gate5, bridge, runtime, tournament, candidate, or EGO-mainline path is authorized.

## Contract

The checker must parse the reconciled `SURFACE-ADMISSION-CONTRACT-HARDENING-001A` `result.json` and `readback.json`, require top-level `contract_hardened_pass`, require G1-G14 readback pass evidence, require anti-blacklist and reason-specific positive/counter controls, and reject task-card manifests that replace artifact-backed dependency with prose mention.

Allowed enforcement verdicts:

- `contract_enforcement_pass`
- `contract_enforcement_refused`
- `invalid_enforcement_harness`

The checker must reject future manifests that request candidate behavior, Gate5, bridge, runtime, tournament, EGO-mainline work, `mechanism_score`, false full-suite pass claims after a timeout, old COMPOSITE/CTSR/ACTION surfaces as mechanism evidence, or any claim that treats the hardened contract as mechanism validity, Gate4/Gate5 validity, readiness, agency, autonomy, consciousness, emotion, subjectivity, companion readiness, EGO readiness, runtime readiness, stable user benefit, or mainline effect.

## Evidence Boundary

Generated evidence is limited to task-authorization hygiene only. It records parser/check invocations, file readback, hostile synthetic controls, result/readback parse status, run id, input paths, referenced hardening tag, aggregation rule, and code path hash.

This does not prove mechanism validity, Gate4 validity, Gate5 validity, candidate behavior, agency, autonomy, consciousness, emotion, subjectivity, EGO readiness, runtime readiness, companion readiness, stable user benefit, or mainline effect.

## Auto-Remote-Anchor

Auto-Remote-Anchor: conditional

Remote anchoring is allowed only if `contract_enforcement_pass` is emitted, result/readback artifacts parse, E1-E18 pass, old frozen artifacts remain unchanged, no mechanism surface/candidate/mechanism score/Gate5/bridge/runtime/tournament/EGO-mainline file is created, final worktree is clean after commit, and branch/tag/hash readback is exact. The claim ceiling for any anchor is remote-anchor publication and verification only.
