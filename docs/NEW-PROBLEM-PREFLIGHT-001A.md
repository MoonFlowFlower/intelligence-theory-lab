## 2. Why This Task Exists

The old proxy compressed a possible mechanism theory into an output-level toy task:

```text
history -> label
```

That proxy collapsed because fair full-history cheap controls could solve the target.

This task must define a better proxy whose evidence target is:

```text
intervention -> internal update path -> later behavior change
```

The new proxy must not ask whether a witness can output the correct label.
It must ask whether an allowed update process produces state changes and later behavior effects that remain distinguishable from fair cheap controls under intervention, trace/replay, ablation, deletion, and counterfactual probes.

## 3. Correct Problem

Define a bounded future preflight problem answering:

```text
Can a bounded mechanism show intervention-sensitive internal update,
counterfactual action-conditioned state change,
or online adaptation under distribution shift
that remains distinguishable from fair full-history cheap controls
under trace/replay, ablation, deletion, and counterfactual probes?
```

This task must not prove that such a mechanism exists.
It must only decide whether a future executable preflight can be cleanly specified.


and if the proposed proxy is not obviously reducible to output prediction, trace theater, graph/cache replay, FSM update, summary statistic, kNN retrieval, or random representation.

### H0 — No Clean Proxy Contract Yet

Return failure if:

```text

the trace does not causally affect future behavior
the intervention does not alter update path
deletion or freezing has no expected behavioral consequence
cheap controls can be disabled only by construction
resource constraints are asymmetric

trace-only replay can plausibly reproduce all evidence
behavior-only replay can plausibly reproduce all evidence
```

Default expectation should be H0 unless the contract survives adversarial audit.

## 7. Candidate Proxy Families to Compare

Codex must compare at least three bounded proxy candidates, but must not implement them.

### P1 — Intervention-Sensitive State Update Proxy

Question:

```text
When the same history is followed by different controlled interventions,
does the system update internal state through different allowed paths,
and do those differences causally affect later behavior?
```

Required probes:

```text
state intervention
memory deletion
representation freezing
prediction-error injection
counterfactual action substitution
observation perturbation
history-preserving causal perturbation
```

Primary risk:

```text
graph/cache trace generator reproduces the same trace and future behavior
```

### P2 — Online Adaptation Under Distribution Shift Proxy

Question:

```text
When the environment rule shifts after training or after partial exposure,
does the system update from new experience in a way that cannot be matched
by fair online cheap controls under the same update access?
```

Required controls:

```text
online count/statistic learner
online FSM
online graph/cache
online kNN / episodic retrieval
online summary statistic
online causal table
```

Primary risk:

```text
cheap online controls match adaptation once given fair update access
```

### P3 — Causal Model Update Proxy

Question:

```text
Can the system distinguish intervention-generated evidence from passive correlation
and update future action choices accordingly?
```

Required controls:

```text
full-history causal table
intervention-labeled graph cache
model-based control baseline
causal summary statistic
oracle causal-state probe
```

Primary risk:

```text
a graph/cache or causal table baseline matches all intervention probes
```

### P4 — Resource-Aware Process Proxy

Question:

```text
Under the same memory, update, and replay budget, does the proposed mechanism
show a structural advantage in intervention-sensitive online update?
```

This is optional and must be treated as a constraint, not a standalone claim.

Forbidden use:

```text
giving witness more memory
giving controls less memory
banning cache or retrieval because they are too strong
```

### P5 — Non-Affective Regulatory Scalar Boundary

This may be included only as a boundary note, not as primary proxy.

Allowed wording:

```text
prediction-error budget
uncertainty pressure
internal cost estimate
resource depletion signal
```

Forbidden wording:

```text
emotion
desire
preference in the subjective sense
liking
happiness
suffering
viability claim
functional subjectivity
companion readiness
```

If Codex cannot keep this boundary clean, P5 must be excluded.
