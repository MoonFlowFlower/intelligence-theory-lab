# Human Review Gate

Human review is mandatory after every cycle.

## Review Questions

```text
Is the lab rotating through the same theory family?
Did the successor cite and address predecessor failures?
Did kill-test strength increase?
Did candidate complexity increase without stronger evidence?
Are baselines strong enough for the obvious shortcut?
Did any metric become an agent feature?
Did any trace-only signal get promoted to control-loop mechanism?
Did any score-only effect get promoted to action causality?
```

## Stop-Loss Rules

Pause the program if:

```text
three consecutive cycles are theory renames
two consecutive cycles fail by the same shortcut
candidate complexity rises while kill-test strength stays flat
negative evidence is not cited by successor theories
human review finds no new invariant
```

The human reviewer may authorize only the next bounded cycle, not indefinite autonomy.
