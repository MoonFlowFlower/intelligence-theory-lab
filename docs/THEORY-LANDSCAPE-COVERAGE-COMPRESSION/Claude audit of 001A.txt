**散文层是安全的,机器可读层不是——而 Codex canonicalization 只会消费机器可读层。**

§9 的 `mandatory_reference_set.json` 把 §3 中刻意区分的五类(A 内部证据链 / B 治理方法 / C 机制参考 / D 架构覆盖 / E baseline)压平成单一数组 `must_include_in_ego_mainline_admission_task_card`,其中 `hyperon`、`soar`、`act_r`、`nars` 与 `causal_eval_ablation`、`red_team_evaluation` 并列、无角色字段区分。同时 §3A 的内部证据链(001B invalidation、001C suspension、negative evidence preservation)从该 JSON 中**整体消失**。所有防采用误读的护栏(§2 表头免责、§3C "Not adopted as architecture"、§7 not-allowed 清单)都只存在于散文中,不在 schema 里。canonicalization 后唯一存活的层恰好是不安全的那一层:读 JSON 的下游会得出"Hyperon 是 EGO mainline admission card 的 mandatory reference"。
