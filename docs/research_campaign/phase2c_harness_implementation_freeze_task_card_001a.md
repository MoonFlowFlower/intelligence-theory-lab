## Computed-Evidence Provenance Gate

Future scores must come from callable producers. Static verdict dictionaries,
handwritten scores, unconditional clean reports, and tests that only assert pass
are forbidden.

Every score must record:

- `producer_function`;
- input artifacts;
- `run_id`;
- seed/context/episode ids;
- aggregation rule;
- code path hash.

Baselines must be independent callable implementations. Ablations must rerun
episodes under real interventions. Leakage scans must run a real scanner with
at least one positive-control case. Replay must recompute candidate-free
behavior from serialized state and observation.
