# 4. Frozen mathematical skeleton

Do not modify this skeleton.

## 4.1 Sets

Finite latent state set:

[
S = {s_0, s_1, ..., s_{n-1}}
]

Finite observation alphabet:

[
O = {o_0, o_1, ..., o_{m-1}}
]

Finite action set:

[
A = {a_0, a_1, ..., a_{k-1}}
]

## 4.2 Belief state

The learner maintains a belief distribution:

[
b_t(s) = P(s_t=s \mid h_t)
]

where (h_t) is the history available before choosing or evaluating action (a_t).

(b_t) must be logged before and after update.

## 4.3 Action-conditioned transition model

The learner maintains:

[
T_\theta(s' \mid s,a)
]

This must be represented by pseudo-counts or an equivalent explicit probability table.

Do not replace this with a neural network, LLM, retrieval store, prompt, or heuristic policy.

## 4.4 Observation model

The learner maintains:

[
O_\theta(o \mid s')
]

This must also be represented by pseudo-counts or an equivalent explicit probability table.

## 4.5 Prediction

For each candidate action (a \in A), compute predicted next-state belief:

[
\hat b_t^{(a)}(s') = \sum_s b_t(s)T_\theta(s' \mid s,a)
]

Then compute next-observation predictive distribution:

[
\hat P_t^{(a)}(o) = \sum_{s'} \hat b_t^{(a)}(s')O_\theta(o \mid s')
]

You must log raw predictions for all actions before observing (o_{t+1}).

## 4.6 Primary prediction target

Primary prediction target:

[
o_{t+1}
]

Do not change the target after seeing results.

## 4.7 Prediction error

Primary error:

[
e_{t+1} = -\log \hat P_t^{(a_t)}(o_{t+1})
]

Use numerical smoothing only if pre-declared in config.

## 4.8 Uncertainty

Primary uncertainty diagnostic:

[
H(\hat P_t^{(a_t)})
]

Calibration metrics:

* rolling NLL
* Brier score
* ECE only if sample size and binning policy are suitable

NLL and Brier are primary. ECE is secondary.

## 4.9 Belief update

After observing (o_{t+1}), compute posterior responsibility:

[
\xi_t(s,s') \propto b_t(s)T_\theta(s' \mid s,a_t)O_\theta(o_{t+1}\mid s')
]

Normalize:

[
\sum_{s,s'} \xi_t(s,s') = 1
]

Then:

[
b_{t+1}(s') = \sum_s \xi_t(s,s')
]

Log `belief_pre`, `belief_post`, and `delta_belief`.

## 4.10 Model learning

If `claim_mode = belief_plus_theta`, update pseudo-counts:

[
C_T(s,a_t,s') \leftarrow C_T(s,a_t,s') + \eta \xi_t(s,s')
]

[
C_O(s',o_{t+1}) \leftarrow C_O(s',o_{t+1}) + \eta b_{t+1}(s')
]

Then renormalize (T_\theta) and (O_\theta).

If `claim_mode = belief_only`, do not claim theta-learning.

Theta-learning claims require:

* `theta_T_pre`
* `theta_T_post`
* `theta_O_pre`
* `theta_O_post`
* `delta_theta_derived`
* frozen-theta baseline
* rule-shift or transition-reversal perturbation

## 4.11 Counterfactual action contrast

For the same history (h_t), compute predictions for all (a \in A):

[
{\hat P_t^{(a)}(o)}_{a \in A}
]

Compute pairwise JS divergence or another pre-declared divergence metric.

Raw all-action distributions are canonical evidence.

`action_contrast` is only a derived summary.

## 4.12 Memory / replay status

Core experiment is trace-only.

Replay is disabled.

Retrieval is disabled.

Any `REPLAY_STEP` in the core protocol is immediate protocol failure.

# 8. Experiment environment

Implement at least three regimes.

## 8.1 Action-sensitive regime

Actions must affect hidden-state transition.

Example acceptable structure:

* (S = {0,1,2})
* (A = {left,right,stay})
* (O = {red,green,blue})

Transition depends on action, with optional small noise.

Observation depends on hidden state, with controlled observation noise.

The exact environment rule must be declared in config and logged as `env_rule_id`.

## 8.2 Null-control regime

Actions must not affect next hidden state or next observation distribution.

All-action predictions should collapse within a pre-declared tolerance.

If action predictions separate in null-control regime, fail T3.

## 8.3 Rule-shift / transition-reversal regime

At a declared time or condition, environment transition rule changes.

This is mandatory if `claim_mode = belief_plus_theta`.

The learner must show trace-visible adaptation in theta or fail theta-learning claim.

## 8.4 Spurious correlation trap

Create a condition where action labels correlate with observations but do not causally control transition.

Passive and shuffled-action baselines must be tested here.

If the learner’s apparent action sensitivity survives only through spurious correlation, fail.
