## Red-Team Finding Evaluated

External red-team verdict:

```text
block_hardcoding_or_lookup
```

Core finding:

```text
The 001B executable pass did not execute meaningful baseline comparisons,
ablations, leakage scans, or behavior-causal replay. Baseline scores,
ablation scores, contrast results, clean leakage status, trace deltas, and
candidate score were generated from source constants or self-consistent
artifact construction rather than measured runs. Train contexts and seed
families were decorative or unconsumed. Candidate action did not causally
consume deserialized serialized_state.
```

## Admission Decision

The red-team blocker is admitted.

001B's nominal pass is not usable as downstream positive evidence for EGO

agency, selfhood, consciousness, real relationship learning, real emotion,
subjective experience, stable user benefit, or any future positive bridge
evidence claim.


## Evidence Matrix Summary

| Required finding | Admission |
| --- | --- |
| Baseline scores generated by actual baseline implementations or constants? | Constants. `baseline_comparison()` defines a fixed scores dictionary and candidate score, and `runner.py` calls it without run data. |
| Ablation scores generated by actual reruns or constants? | Constants. `ablation_report()` defines fixed scores and contrast booleans. |
| Leakage scans real and fail-able? | No. `leakage_report()` returns every check as clean and all equivalence flags false. |
| Trace deltas measured or constant? | Constant. Trace rows write fixed deltas `(1.0, 0.0, 1.0)`. |
| Counterfactual pairs consumed from frozen manifest? | No. Build loop consumes heldout contexts; counterfactual state is selected by `_find_counterfactual_state()` rejection search. |
| Replay recomputes candidate action from serialized state plus observation? | No. Replay checks hash self-consistency, not behavior-causal recomputation. |
| Observations available for behavior-causal replay? | No. Trace and serialized snapshots contain hashes, not observation objects. |
| Provenance `source_trace_ids` resolvable? | No. They are generated strings such as `source_trace_000`; trace rows do not contain matching trace objects. |
| Train contexts and seed families consumed? | No meaningful consumption found. They are frozen in distribution metadata but not used by the admission run. |
| Candidate action consumes deserialized serialized state? | No. Candidate action is computed from `pre_state` before constructing `serialized_state`; no deserialize path is executed. |
