## Problem definition

The prior governance stack correctly prevented scientific claims on saturated
or invalid instruments, but several clauses also prevented building a bounded
reference learner until headroom had already been established. That coupling
creates an audit Zeno trap: the product/foundation and a useful reference probe
never exist, while instrument repairs continue indefinitely.

The correction is narrow:

1. preserve headroom, access-parity, leakage, baseline, ablation, and replay
   gates for formal claims;
2. permit a separately carded, default-off `K0-R` reference implementation only
   after the H0 contract is banked;
3. keep K0-R outside formal evidence until H1 is accepted and an immutable
   wheel/CLI freeze exists;
4. replace a monolithic result verdict with component-scoped evidence plus a
   separate rival qualifier.

Semantics:

- `NOT_TESTED`: required pre-registered contrasts were not validly executed.
- `INVALID_INSTRUMENT`: a mapped integrity or power/MDE dependency failed;
  this is not a mechanism-negative verdict.
- `ABSENT`: instrument and power were valid, but the mapped causal gate failed
  within the frozen scope.
- `PRESENT_BOUNDED`: the mapped causal gate passed within the frozen scope.
- rival qualifiers never upgrade or erase component evidence.
- invalid/unrun rival data maps to `RIVAL_NOT_RUN` with a reason.
- `V_special` is defined only as specialness relative to frozen panel `P`,
  budget `B`, and distribution `D`; its evidence state is `NOT_TESTED` when no
  valid rival run exists, `ABSENT` on `RIVAL_SATURATED`, and
  `PRESENT_BOUNDED` on `RIVAL_SEPARATED`.
- no unified `K - max(C)` or global pass verdict is permitted.
- `score_provenance` must be null for `NOT_TESTED` and must contain the complete
  computed provenance object for `INVALID_INSTRUMENT`, `ABSENT`, and
  `PRESENT_BOUNDED`; fabricated placeholder strings are forbidden.

## Protocol boundary

- Fresh-init resets checkpoint, optimizer, memory, replay buffer, kernel state,
  RNG, and episode history per family. It can show one architecture learns
  separately; it cannot alone establish transfer.
- Persistent-sequence retains checkpoint, optimizer, memory, replay buffer, RNG,
  and kernel state across the frozen family order and limited permutations. It
  must include full carryover, full fresh-init, checkpoint-only, replay-reset,
  and memory-reset controls and report forward transfer, retention,
  interference, order sensitivity, and resource growth.
- `family_id`, split identity, sequence position, and heldout labels are
  evaluator-only and forbidden kernel inputs.
