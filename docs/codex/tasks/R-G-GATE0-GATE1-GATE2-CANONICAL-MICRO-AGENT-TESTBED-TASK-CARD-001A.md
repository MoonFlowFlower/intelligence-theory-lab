## Core Hypothesis

If a minimal agent loop can combine:

```text
1. action-conditioned prediction error and belief/model update;
2. replay/consolidation linked to later behavior;
3. controllability error and self-boundary update linked to later action selection;
```

while preserving one canonical state schema, one hash-chained trace, one
linkage contract, fair baselines, required ablations, leakage controls, and a
bounded claim ceiling, then it may provide bounded integrated micro-agent
testbed readiness evidence.

This is a task-card hypothesis only. This task does not test the hypothesis.
