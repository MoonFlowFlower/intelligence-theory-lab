## real objective

SUBJECT claim is empty. Only a construction that survives all closers under equal resources with a
falsifiable non-oracle criterion earns the (expensive) measurement-design phase. Realistic non-closure

### U-boundary non-vacuity requirement (anti-tautology)  [R3 / Patch D]
U-boundary MUST be pre-registered in mechanistic/algorithmic terms, NOT outcome terms.
  Forbidden ⇒ U_BOUNDARY_OVERBROAD: U = "whatever succeeds on C" / "any process producing the same
    trace" / "any adaptive online learner" / "any system that builds a useful self-model".
  Forbidden ⇒ U_EQUIVALENCE_POST_HOC: a U-equivalence class defined AFTER seeing which baseline matches.
  Required: minimal operational U definition · observable implementation constraints · a U-disabled
    ablation · AT LEAST ONE STRONG U-NON-EQUIVALENT BASELINE that remains admissible · a pre-declared
    U-equivalence test.
  Anti-strawman: that strong U-non-equivalent baseline MUST be a member of the frozen family B1–B9 at
    equal R, judged by the same no-strawman standard as all baselines — not an ad-hoc weak baseline made
    only to satisfy this clause. If no fair-family baseline can be pre-declared U-non-equivalent, U has
    swallowed the baseline space ⇒ U_BOUNDARY_OVERBROAD.
  No U-boundary: mechanism/subject claim ⇒ ADMIN_CLOSED_NO_FALSIFIABLE_MECHANISM;
                 capability-only claim ⇒ ROUTE_TO_FORK_B_CAPABILITY_BENCHMARK.

## generated-access fairness  [R2/R3]
### S-1 counterfactual baseline participation protocol (mandatory when generated access is invoked)
  - M and every B_i receive the SAME R: initial resources, embodiment/interface, environmental laws,
    seed distribution, intervention budget, memory/compute budget, viability objective J|V.
  - Each B_i GENERATES ITS OWN access path; a B_i is NOT evaluated by replaying M's realized path
    (unless the claim is explicitly about path-following robustness).
  - Score compares DISTRIBUTIONS over generated traces, NOT the same realized trace.
  Failure terminals: PATH_REPLAY_LEAK · GENERATED_ACCESS_ASYMMETRY · NO_COUNTERFACTUAL_BASELINE_PROTOCOL.
### generated-trajectory comparability / curriculum-confound guard  [R3 / Patch E]
  When M and B_i generate different access paths, the scorer MUST specify: ex-ante seed distribution ·
  shared environment law · horizon and stopping rule · viability/objective J|V INDEPENDENT of M's
  realized path · difficulty/novelty/coverage diagnostics over generated curricula · paired (common
  random numbers) or distribution-level comparison.
  Failure terminals: TRAJECTORY_DISTRIBUTION_CONFOUND · SELF_CURRICULUM_EASY_MODE ·
  GENERATED_DIFFICULTY_MISMATCH · UNDERPOWERED_GENERATED_ACCESS.
  (Note: this fair comparison — distributions over counterfactual self-generated trajectories — is
  intrinsically high-variance and expensive; that cost is part of the fork-A price even for SURVIVES.)

## U-equivalence adjudication  [R2/R3 / Patch B-2 + F]
For any baseline B_i that MATCHES M under the S-1 protocol at equal R:
  - B_i is U-disabled or pre-declared U-NON-equivalent ⇒ FORK_A_SHADOW_DOMINATED (U not necessary).
  - B_i matches only by implementing a pre-declared U-EQUIVALENT process ⇒ MECHANISM_FAMILY_REPLICATION.
  - B_i is M's exact U under another name ⇒ PARITY_CLONE_INVALID_AS_SHADOW.
Adjudication rule (no intuition): B_i is classified U-equivalent ONLY IF it satisfies the pre-registered
  U-boundary AND its U-like component is identifiable in trace/implementation/ablation AND disabling that
  component destroys its match AND the classification is made before any outcome-based relabeling.
  If B_i matches but U-equivalence is NOT diagnosable ⇒ U_EQUIVALENCE_UNDETERMINED (neither
  SHADOW_DOMINATED nor MECHANISM_FAMILY_REPLICATION; requires a narrower tuple or a new diagnostic).

## hostile closers (reduction / fires when / escape burden)
K-A1 META-MDP REDUCIBILITY (split ideal vs resource-matched):
  K-A1a IDEAL_OBJECT_EXISTS — if G is formalizable as a fixed stochastic game / meta-MDP / path measure,
    an ideal Bayes-optimal reference is DEFINABLE. This CAPS the claim at capability and BLOCKS
    subject/mechanism overclaim, but does NOT by itself prove an equal-resource shadow exists.
  K-A1b RESOURCE_MATCHED_SHADOW_EXISTS — to close by DOMINATION, a resource-matched baseline in B must
    approximate/dominate M under R. If the ideal exists but no resource-matched shadow is feasible ⇒
    route to K-A2 / CAPABILITY_NOT_SUBJECT, NOT automatic collapse.
K-A2 AMORTIZABILITY / LEARNABILITY DICHOTOMY (centerpiece):
  - structure captured by a FAIR equal-resource adaptive baseline (B1/B8/B9/…) ⇒ FORK_A_SHADOW_DOMINATED;
  - M's edge is only resource/compression/sample-efficiency ⇒ CAPABILITY_NOT_SUBJECT, UNLESS shown a
    NON-TRANSFERABLE MECHANISM NECESSITY (cashed out as: beats the FULL B family incl. B7 U-disabled at
    equal R, AND a U-ablation shows the contested mechanism necessary) rather than architecture/efficiency;
  - no baseline specifiable because no stable contract ⇒ SPECIFICATION_GAP / UNMEASURABLE;
  - genuinely NO exploitable structure ⇒ NON_LEARNABLE_NO_SIGNAL (narrow: truly structureless only).
K-A3 MEASUREMENT / FALSIFIABILITY (route, don't auto-kill advantage-over-baseline):
  advantage-over-B is a legitimate evidence form. Route: incomplete B ⇒ UNDERDEFINED_BASELINE_SET; win is
  resource/sample-efficiency ⇒ CAPABILITY_NOT_SUBJECT; C scored vs a fixed target ⇒ re-imposes a fixed
  reference (→K-A1) or oracle (→CDAP Check B); C with neither baseline nor reference ⇒
  UNMEASURABLE_NOT_FALSIFIABLE ("looks alive," forbidden).
K-A4 SELF-PLAY / CO-EVOLUTION (reducibility, not convergence):
  fixed-rule self-play is a fixed stochastic game / population process ⇒ falls under K-A1 /
  resource-matched population baselines (B2/B6), whether or not the dynamics converge (cycles /
  multi-equilibria / path-dependence do not save it). Another instance of the same learner is NOT a
  shadow for the mechanism claim; it only shows the effect is species / mechanism-family-level, not
  individual-M-specific (→ MECHANISM_FAMILY_REPLICATION). To close the mechanism claim, the matching
  baseline must be U-disabled or pre-declared U-non-equivalent.
K-A5 EMBODIMENT ADDS ACCESS, NOT SEPARABILITY: embodiment changes the access tuple, not identifiability;
  a fixed-prior embodied MDP has an ideal reference (K-A1a); self/boundary is obs-decodable /
  interventionally-saturated or oracle-labeled (CDAP ROW 6/7). Escapes only via S-1.
K-A6 CROSS-EPISODE MEMORY = GRAPH-CACHE/HISTORY baseline (B3/B5): fixed-prior accumulation ⇒ amortized
  ⇒ dominated; escapes only via genuinely non-amortizable accumulation (→ K-A2 middle → capability / spec-gap).

A fork-A FUNCTIONAL-SUBJECT separation survives only if a construction beats the FULL fair family
(B1–B9 at equal R, incl. B7 U-disabled) on a generated-access / no-closing-reference process, with a
falsifiable non-oracle C under the S-1 + curriculum guards, AND the advantage is a non-transferable

fork B) / SPECIFICATION_GAP / UNMEASURABLE. A subject foothold is near-empty; if it appears, presume a
bug (baseline gap / access asymmetry / U-boundary overbreadth) first.
