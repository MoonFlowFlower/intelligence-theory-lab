prediction, Gate1 replay/consolidation, Gate2 controllability/self-boundary,
and Gate3 viability/action-priority updates remain traceable through one

## Hard Shared-State Requirement

create four isolated gate outputs and stitch them together after the fact. It
must not introduce hidden orchestration logic, a second schema, side cache,
reward table, threshold table, stitched summary table, or test-only policy
layer.

after execution. If any tracked old artifact changes during the executable run
or full-suite verification, the task must emit a failure artifact or fail with
an explicit old-artifact mutation verdict rather than silently restoring and
passing.
