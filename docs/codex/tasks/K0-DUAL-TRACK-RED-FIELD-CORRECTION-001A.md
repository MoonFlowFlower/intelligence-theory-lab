## 4. Frozen correction semantics

The machine source is `red_field_correction_contract.json`. It is an additive
overlay whose conflicting terminal, formula, power, coverage, RNG, and claim-
ceiling fields take precedence; all non-conflicting original Red constraints
remain binding.

### C1 - V_special terminal mapping

`PRESENT_BOUNDED` requires every referenced component to be admissible and
`PRESENT_BOUNDED`, `CONTROL_SEPARATED`, `RIVAL_SEPARATED`, and all integrity
dependencies valid. Powered shortcut parity/saturation, powered rival parity/
saturation, or candidate domination by either panel maps to `ABSENT`.
Underpowered required comparison or invalid required dependency maps to
`INVALID_INSTRUMENT`. Inconclusive never maps to `ABSENT` or
`PRESENT_BOUNDED`.

### C2 - component formulas

All six formula rows freeze the required fields named in the machine contract.
Every mandatory causal contrast runs; a missing, orphaned, or unused mapped
contrast fails closed. Aggregation operators are fixed before H0. A
`PRESENT_BOUNDED` component always permits only its candidate-internal causal
signature; a bounded control-non-equivalence claim additionally requires
`CONTROL_SEPARATED`. Rival qualification never erases another component's
evidence state.

### C3 - superiority terminals

The effective control axis adds `CONTROL_DOMINATED`; the effective rival axis
adds `RIVAL_DOMINATED`. Candidate powered superiority maps to `*_SEPARATED`,
powered parity or preregistered ceiling saturation maps to
`CONTROL_EQUIVALENT`/`RIVAL_SATURATED`, control/rival powered superiority maps
to `*_DOMINATED`, and underpowered maps to `*_INCONCLUSIVE`.
`CONTROL_BETTER` is not an equivalence subtype in the effective schema.

### C4 - powered causal absence

Every causal-ablation no-effect mapping and every `evidence_state=ABSENT`
decision requires a valid full arm, valid intervention arm, a frozen powered
equivalence/noninferiority decision, and computed power at the SESOI meeting the
target. Failure to reject an effect is not absence. Causal underpower maps to
`INVALID_INSTRUMENT`.

### C5 - exhaustive signature coverage

Every original arm assignment, every component-mapped arm, every integrity
control, and every original or correction contrast must be covered. Orphan arms
and unused contrasts map to `INVALID_INSTRUMENT`. Future H0 must generate
`control_signature_coverage_report.json` with the exact fields and four
simulation cases frozen in the machine contract.

### C6 - per-source RNG evidence

Every original RNG source gets its own required entry. The original run is not
a recompute. Two recomputes must use distinct PIDs and temp directories and
record the exact fresh-process fields frozen in the contract.

### C7 - power design and provenance

Future H0 must instantiate exactly one valid fixed-seed or sequential-seed
design. MDE/power is callable computed evidence with exact producer/input/run/
seed/aggregation/code-hash provenance. Null fixed count plus vague sequential
prose, hand-written power/MDE, and post-result N extension are forbidden.

### C8 - exact machine claim ceiling

The sole allowed machine claim and exact forbidden list are the JSON block in
this card and the contract `claim_ceiling`. The validator must parse the
committed card block and require exact equality.
