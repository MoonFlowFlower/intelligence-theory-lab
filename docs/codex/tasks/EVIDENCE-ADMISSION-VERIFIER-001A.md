# EVIDENCE-ADMISSION-VERIFIER-001A

## Task Card

task_id: EVIDENCE-ADMISSION-VERIFIER-001A

problem_definition: Existing Gate evidence can appear pass-shaped even when reported scores, baselines, ablations, leakage checks, or replay checks are not backed by callable provenance. Build a standalone verifier that admits citation only when machine-readable evidence proves callable computation and required controls.

current_stage: engineering-governance / evidence-admission only

current_layer: engineering implementation layer, with mechanism claims forbidden

mainline_target: none; standalone CLI/library only

enabled_state_requirement: verifier can be invoked as `python -m evidence_admission_verifier_001a <bundle_path> --out <artifact_dir>` against an evidence bundle directory

real_trigger_evidence_requirement: the verifier must inspect bundle files, compute block reasons from machine-readable provenance/control rows, and write admission artifacts without relying on result/report verdict strings

hypothesis: A small standalone verifier can prevent citation of report-shaped false passes by requiring invocation ledgers, metric provenance, callable baselines, real ablation reruns, leakage positive controls, behavior replay recomputation, frozen input consumption, and bounded claim ceilings.

strongest_baseline: Codex edits only `result.json` or `report.md` to claim pass/readiness while leaving callable provenance, baseline, ablation, leakage, replay, or frozen-input evidence absent.

ablation_requirement: Focused tests must remove one required evidence family at a time and verify the verifier blocks for the corresponding computed reason.

trace_replay_requirement: Replay evidence is admissible only when bundle rows state behavior was recomputed from serialized state plus observation; hash-only or stored-action replay must block.

computed_evidence_provenance_gate: Decisions must be derived from parsed JSON/JSONL rows and recomputable from `admission_decision.json` and `block_reason_matrix.json`; `verdict`, `pass`, `ready`, markdown summaries, and report text are ignored unless backed by required machine-readable rows.

acceptance_gate:
- clean minimal fixture is admitted for citation
- artificial fake-pass fixture blocks
- missing-baseline fixture blocks
- missing-ablation-rerun fixture blocks
- leakage-clean-without-positive-control fixture blocks
- replay-hash-only fixture blocks
- editing only `result.json` or `report.md` cannot turn a blocked bundle into admitted
- focused tests pass
- no existing Gate3, Gate4, mainline, runtime, bridge, or old artifact files are modified

claim_ceiling: standalone evidence-admission filtering for future citation only; no Gate repair, no mechanism validity, no Gate4 validity, no EGO readiness, no runtime readiness, no agency, no consciousness, no emotion, no autonomy, no stable user benefit.

stop_condition: Stop if implementation requires modifying existing Gate3/Gate4/mainline logic, rewriting historical artifacts, weakening required evidence families, or treating text verdicts as evidence.
