# ROUTE-STATE-MACHINE-001B-CURRENT-FRONTIER-GATE

## Task id

ROUTE-STATE-MACHINE-001B-CURRENT-FRONTIER-GATE

## Problem definition

Extend the existing local route-state-machine governance validator so the
ROUTE-STATE-MACHINE-001A artifact bundle records and validates a single current
frontier route. The current frontier for this task is
`N2-SBMC-ENV-REDESIGN-001A`, registered only as a design/pre-registration
frontier with no mechanism experiment, no scoring, no EGO runtime integration,
and no theory/mechanism validity claim.

## Current layer

Engineering implementation layer, limited to local route-governance validation
and artifact hygiene.

## Current stage

Local current-frontier gate for ROUTE-STATE-MACHINE-001A.

## Mainline target

The local `route_state_machine_001a.routectl` validation/status/dashboard flow
must reject missing or unsafe current-frontier state and must report the
registered N2 frontier without authorizing scoring, experiment execution,
mechanism validity, or theory pressure.

## Source readback

Preflight readback of `docs/research/FSP-STAGE-LEDGER.md` must verify that
`L-014` or equivalent current ledger evidence supports registering
`N2-SBMC-ENV-REDESIGN-001A` as a design/pre-registration current frontier and
also says there is no code/scoring in that bank.

## Hypothesis

Adding a program-level current-frontier record plus route-level source readback
will prevent stale or tombstoned route state from being presented as the active
frontier and will preserve the claim ceiling for N2 as design/pre-registration
only.

## Strongest baseline / shortcut explanation

A static Markdown status pointer or hand-written status report could appear to
identify a current frontier without enforcing any machine-readable safety
conditions. The validator must therefore compute failures from JSON artifacts
and route state, not rely on a prose claim.

## Ablation requirement

Validation must fail under local fixture mutations for:

1. missing `program_state.json`;
2. missing `current_frontier_route_id`;
3. missing current-frontier route directory;
4. TOMBSTONED current-frontier route;
5. empty `program_state.allowed_next_actions`;
6. empty `program_state.forbidden_next_actions`;
7. missing `program_state.claim_ceiling.max`;
8. a REGISTERED current frontier that authorizes mechanism validity, theory
   pressure, scoring, or experiment execution;
9. `N2-SBMC-ENV-REDESIGN-001A` without source readback citing `L-014` or
   equivalent current ledger evidence.

## Collision record

### Candidate A: minimal implementation

- Evidence produced: local CLI validation of program-state and current-frontier
  JSON artifacts plus focused pytest fixture failures.
- Strongest cheap baseline that could match it: a static status file with no
  validator enforcement.
- Leakage / hard-coding risk: validator could special-case route IDs instead of
  validating source-readback and authorization fields.
- Smallest falsifying test: remove `program_state.json` or remove `L-014`
  source readback from the N2 route and observe validation still passing.
- Expected failure mode: schema mismatch with existing route-state artifacts.

### Candidate B: strongest shortcut / baseline explanation

- Evidence produced: Markdown-only current frontier pointer.
- Strongest cheap baseline that could match it: exact same prose update.
- Leakage / hard-coding risk: total; no machine-readable enforcement.
- Smallest falsifying test: CLI validate ignores the pointer.
- Expected failure mode: stale frontier claim survives without validation.

### Candidate C: mechanism-faithful but out-of-scope implementation

- Evidence produced: a new mechanism roadmap or N2 environment/scoring harness.
- Strongest cheap baseline that could match it: graph-closure or lookup-family
  baselines per ledger L-014.
- Leakage / hard-coding risk: high; would violate the no-experiment/no-scoring
  constraint and conflate route governance with mechanism evidence.
- Smallest falsifying test: fair graph-closure baseline saturates reachable
  headroom.
- Expected failure mode: false claim inflation and unauthorized mechanism work.

Selected approach: Candidate A only.
