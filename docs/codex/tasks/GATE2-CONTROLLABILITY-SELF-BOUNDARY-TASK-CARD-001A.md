## Hypothesis

If a system maintains an action-conditioned controllability model that updates
under intervention, predicts which state transitions are self-controllable
versus externally caused, and changes later behavior accordingly, while
remaining distinguishable from identity-tag lookup, retrieval,
count/statistic controls, transition tables, graph caches, frozen
controllability models, oracle environment labels, trace replay hygiene, and
behavior imitation, then it may provide bounded Gate2 self-boundary /
controllability proxy evidence.

This is a future executable hypothesis only. This drafting task does not test
or support the hypothesis.
