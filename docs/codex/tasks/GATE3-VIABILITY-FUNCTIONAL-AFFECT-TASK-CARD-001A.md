## Core Hypothesis

If a system maintains a bounded internal viability model that updates from
action-conditioned and externally caused viability changes, computes viability
error, changes action priority or recovery behavior accordingly, and remains
distinguishable from lookup/table/cache/rule/retrieval/imitation/oracle
controls under ablations and leakage controls, then it may provide bounded
Gate3 viability / functional-affect proxy evidence.

This is a task-card hypothesis only. This task does not test the hypothesis.

```text

  action_id,

  replay/consolidation summaries,
```
